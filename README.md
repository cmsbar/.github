# .github

Org-level GitHub configuration for [**CMSBar**](https://github.com/cmsbar).

- [`profile/README.md`](profile/README.md) — the public profile shown on the
  [organization landing page](https://github.com/cmsbar).

Add shared issue/PR templates, workflows, or community health files here to
have them apply across every repo in the org that doesn't define its own.
